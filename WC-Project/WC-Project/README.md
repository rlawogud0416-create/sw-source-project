# WC - Weather Coordinator

> 날씨 맞춤형 외출복 코디 추천 프로그램

## 프로젝트 정보

- **과목**: 오픈소스설계
- **학번**: 22213505
- **이름**: 김재형

## 개요

매일 아침 옷을 고르느라 시간을 낭비하지 않도록, 본인이 가진 옷을 미리 등록해두고 외출할 시간의 기온만 입력하면 알맞은 코디(상의+하의+아우터)를 자동으로 추천해주는 CLI 기반 프로그램이다.

C++17 표준으로 작성되었으며, 객체지향 설계 원칙(상속, 다형성, 캡슐화, 책임 분리)을 적극 활용했다. 외부 라이브러리 없이 표준 라이브러리만으로 동작한다.

## 주요 기능

- 옷 추가 / 조회 / 수정 / 삭제 (CRUD)
- 카테고리별 필터링 (상의 / 하의 / 아우터)
- 기온 입력 기반 코디 추천 (무작위 조합)
- 추천 결과 재요청
- 텍스트 파일(`wardrobe.txt`)에 자동 저장 / 복원

## 빌드 방법

자세한 내용은 [`BUILD.md`](./BUILD.md) 참고.

### Windows (Visual Studio)

1. Visual Studio에서 새 콘솔 프로젝트 생성
2. `src/` 하위의 모든 `.h`, `.cpp` 파일 추가
3. `프로젝트 속성 → C/C++ → 코드 생성 → 런타임 라이브러리`를 **`/MT (다중 스레드)`** 로 변경
4. **`Release | x64`** 모드로 빌드 (Ctrl + Shift + B)

### Linux / macOS

```bash
make           # 일반 빌드
make static    # 정적 링크 빌드 (배포용)
make run       # 빌드 후 실행
make clean     # 빌드 결과물 정리
```

또는 수동으로:

```bash
g++ -std=c++17 -O2 -o WC src/*.cpp
./WC
```

## 실행 방법

빌드된 실행 파일(`WC.exe` 또는 `WC`)을 실행하면 메인 메뉴가 나타난다.

```
============================================================
         WC - Weather Coordinator (v1.0)
            날씨 맞춤형 외출복 코디 추천
============================================================
  현재 등록된 옷: 0벌 (상의 0 / 하의 0 / 아우터 0)
------------------------------------------------------------
  [ 1 ] 옷 추가하기
  [ 2 ] 옷장 보기
  [ 3 ] 옷 정보 수정하기
  [ 4 ] 옷 삭제하기
  [ 5 ] 코디 추천받기
  [ 0 ] 프로그램 종료
============================================================
  메뉴를 선택하세요 >> _
```

> 💡 **샘플 데이터 사용**: `data/wardrobe.txt`를 실행 파일과 같은 폴더에 복사한 뒤 실행하면 미리 11벌의 옷이 등록된 상태로 시작할 수 있다.
